# Nova Visual Platform

Nova Visual Platform is an immersive, standalone visual discovery and creator platform designed for photographers, designers, and visual curators. It offers intentional, aesthetic feed exploration and creator monetization tools with zero external dependencies.

## 🔗 Live Demo

Experience the platform live:
👉 [Nova Visual Platform Live Demo](https://renusrisai29.github.io/Nova-Visual-Platform/)

---

## ✨ Key Features

- **Thematic Visual Worlds**: Explore curated collections across Architecture, Photography, Travel, Design, Fashion, AI Art, Nature, and Technology.
- **Dynamic Feed Sorting**: Browse visuals using For You, Following, Fresh, Trending, and Nearby filters.
- **Creator Studio & Analytics**: View audience reach with interactive SVG impression charts and revenue diversification metrics.
- **Creator Monetization**: Support creators directly via Patron Tipping, Studio Circle subscriptions, and commercial brand campaigns.
- **Create Studio**: Publish visual studies with a live side-by-side card preview and automated GPS metadata extraction from images.
- **Interactive Discussions & Chat**: Leave comments, engage in discussions, and exchange direct messages with simulated creator replies.
- **Dark & Light Modes**: Seamlessly toggle between Obsidian Dark and Lumina Light themes.
- **Zero-Dependency SPA**: Runs 100% in your browser with persistent client-side state saved to `localStorage`.

## 🚀 How to Run the Project

No installation, build tools, or packages are required.

### Option 1: Direct in Browser (Easiest)
Double-click `index.html` (or `Nova-Visual-Platform.html`) to open the app directly in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Recommended)
You can also run a simple local web server:

**Using Python:**
```bash
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

**Using Node.js:**
```bash
npx serve .
```
Then open the local URL displayed in your terminal.
